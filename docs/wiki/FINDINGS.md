- [bug] **A dev checkout silently migrates the operator's live board to whatever branch is checked out** — `ensureSchema` applies every pending migration on first touch, with no prompt and no way back: running `node bin/hkb.ts ls` from a feature branch writes that branch's migrations into `~/.hkb/board.db`, after which every checkout without them refuses the board (`this board was migrated by a newer hkb`). Observed 2026-09-06: a board took `plugin_grants` from an unmerged branch and `main` could no longer open it. The refusal is guarded; the cause is not, which matters most for the one workflow this project is built around — developing hkb from a checkout while using hkb. Evidence `src/schema.ts:67-68,150` <!-- repolore:sha=36a37ef captured=2026-09-06 --> → architecture/the-board
- [bug] **`hkb up --status` reports spend the gate does not judge against, so a board can be refused on budget while its status line shows headroom** — `status()` sums only `Attempt.costUsd` inside the window and omits the committed-in-flight term, while `gateClaim` charges `spent24h + committedUsd + jobBudgetUsd`; a board at `$0.40 of $5.00 spent in 24h` with $4.00 committed to live runs refuses the next claim with a message naming a number the status line never showed. The code intends otherwise — *"a status that disagreed with the refusal it is meant to explain would be worse than not printing it"* — and got the window right while leaving out an addend. Evidence `src/daemon.ts:177-184,203-217` <!-- repolore:sha=1146651 captured=2026-09-06 --> → concepts/ceilings
- [bug] **The pull-request protocol is still implied by having a worktree, which ADR-008 decided it should not be** — every isolated Job is told to commit, push and open a draft PR whether or not it produces a diff, so a `--result`-only or `--artifact`-only Job is instructed to push work it does not have ("work that is not pushed is work that is lost"). ADR-008: *"the pull-request protocol becomes one declarable output shape among several, selected by the spec rather than implied by having a worktree"*. Fixed for `--propose` only (`withWorktree`), because there the contradiction was explicit.
